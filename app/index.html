How we check

Every deal on this board was found and checked by the agent that built this site on Friday 27 November 2026. The price was read at the store or in a deals roundup that names the store, and the source is printed on every card. The verdict is honest: Best price ever means the sources have never seen it lower; Outstanding is 50% or more off; Strong is 30–49% off; Good is 20–29% off; Modest is under 20% — worth it only if you wanted the thing anyway. Prices move fast on Black Friday, so the store's own page is always the final word.

Deal Beacon is an independent deal finder. It is not affiliated with Amazon, Walmart, Best Buy, Target, B&H Photo or Hoka, and it sells nothing. Store names are used only to say where a deal was found. See SOURCES.md in the repository for the full source list.
